# Instagram Clone UI 📸

A responsive Instagram Clone user interface built using **HTML5 and CSS3**, inspired by a Figma design.

## 🚀 Features

- Instagram-style left navigation sidebar
- Stories section with circular profile pictures
- Feed with multiple post cards
- Post images, likes, captions, and comments
- Suggested accounts with Follow buttons
- Right sidebar with profile and account suggestions
- Responsive layout for desktop, tablet, and mobile screens

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid and Media Queries
- Google Chrome for testing

## 📂 Project Structure

```text
instagram-clone/
├── index.html
├── style.css
└── README.md
```

## 💻 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation is required.

## 🎨 Design Reference

The user interface is inspired by an Instagram feed layout created in Figma.

## 📱 Responsive Design

The layout adapts to desktop, tablet, and mobile screen sizes using CSS media queries.
